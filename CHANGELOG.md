# Changelog

## 1.1.0 — 2026-11-18
- New **Check size** option: measure the Temp folder every 1, 3, 6, 12 or 24 hours, or on demand only (default: every hour, previously every 10 minutes)
- Daily automatic clean now works even when size checks are on demand only

## 1.0.0 — 2026-11-18
First release.
- Desktop widget showing the size of your Temp folder and how much can be cleaned
- **Clean now** with confirmation; files in use are skipped
- Clean modes: only files older than 1 day (default) or everything not in use
- Automatic clean: off, each time the widget starts, or once a day
- Start with Windows on/off
- About window, tray icon, Open Temp folder
- Listed in *Settings > Apps* with publisher V-Sharp AI Labs Limited
